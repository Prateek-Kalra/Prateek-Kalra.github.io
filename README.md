## Privacy model
The detailed résumé is NOT hosted publicly.

The website now has:
- View LinkedIn
- Request résumé → jumps to Contact
- Request via email → opens an email request

Before publishing, replace:
- `https://www.linkedin.com/` with your actual LinkedIn URL
- `YOUR_EMAIL@example.com` with your professional email

Do not add the confidential résumé PDF to the public repository.

## Publish
Create a public repository named `<your-github-username>.github.io`, upload these files, then enable GitHub Pages from the `main` branch and `/ (root)`.

## AI security
The AI Lab is intentionally browser-only. Never expose a private LLM API key in public JavaScript. A production AI assistant should use a secure backend or enterprise-approved AI service.
